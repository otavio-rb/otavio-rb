## O que eu faço

Desenvolvo aplicações web de ponta a ponta e APIs com foco em TypeScript, React, Next.js, Node.js e .NET. Trabalho desde o desenho da arquitetura (Clean Architecture) e modelagem de bancos relacionais até a entrega em produção com pipelines de CI/CD e containers Docker. Tenho experiência recente com fluxos de automação inteligente, busca semântica em PostgreSQL utilizando pgvector e integração com LLMs via arquitetura RAG.

Nas horas vagas, tenho como hobby o estudo de computação gráfica na web, desenvolvimento de engines e renderização 3D em tempo real com WebGL, Three.js e shaders GLSL, explorando algoritmos de malhagem, física discreta e concorrência com Web Workers.
